## 二、已完成的改造

### 2.1 输出字段：全量重命名为官方名
- 各 transformer 输出字段已按官方返回参数表重命名（如 `totalUnits→units`、`totalAmount→revenue`、`bsrRank→bsr`、`bsrRankCr→bsrCr`、`bsrRankCv→bsrCv`、`reviews→ratings`、`reviewsRate→ratingsRate`、`reviewsIncreasement→ratingsCv`、`primeExclusivePrice→primePrice`、`dimensions→dimension` 等）；`badge{bestSeller,amazonChoice,newRelease,ebc,video}` 统一为官方对象结构。
- 删除与官方重复的冗余字段（`listingQualityScore`、`variationNum`、`badges`、`sellerType`、旧 `ratings` 等）。
- 修复分类映射类 bug：`asin_detail` 的 `skuList/firstRatingDate/primePrice/subcategories`、`aba` 的 `top3Brands`、`keyword_conversion` 的 `top3Asins` 等。

### 2.2 输入参数：名称/类型/必填/默认对齐官方
- `product_research`：参数改名对齐官方（`minRatings/minRating/minBsr*/minUnits/minRevenue/minUnitsCr/dimensionType/sellerNation/badgeBS|AC|NR/availableMonth` 等），修复 `availableMonth` 原本恒不生效。
- `keyword_research`：必填 `includeKeywords` → 官方 `keywords`；补齐 `departments/min*Cr/min*Cv/withYearlyGrowth/minAraClickRate/minGoodsValue/order` 等；修复排序默认被取反的问题。
- `keyword_order`：`reverseType` 改为必填；新增 `order` 对象。
- `aba_research_weekly/monthly`：`orderField/orderDesc` → `order` 对象；补 `searchModel`(1–6)。
- `market_research`：补齐官方维度参数；`newProduct` 默认 3、`size` 默认 50。
- `traffic_extend`：`order` 对象化。
- `traffic_keyword`：新增 `keyword/trafficKeywordTypes/conversionKeywordTypes/order`；`size` 默认 50/最大 100。
- `asin_detail`：返回由分页信封改为官方单对象。

### 2.3 全局（上一轮已完成）
marketplace 枚举校验（US/JP/UK/DE/FR/IT/ES/CA/IN/MX，全工具统一）、缓存键修复（全参数入键）、month 严格校验（yyyyMM+月份 01–12）、matchType 1/2/3 校验、`asins` 单字符串兼容。

### 2.4 修复 tools.json 结构性损坏
`app/tools.json` 中 `keyword_miner` 条目因缺少对象闭合被错误嵌套进 `asin_sales_trend`，导致文件为**非法 JSON**。已修复并校验：21 个条目、名称唯一、与 21 个 handler 一一对应。

## 四、仍然存在的问题

### 🔴 P0（功能不可用 / 语义不符）
1. **`asin_sales_trend` 完全不可用**：该接口走 `api.sellersprite.com` 的 secret-key 通道，当前 Redis 会话无 `secretKey`，实测返回「当前数据服务会话未配置访问凭证」。需补充会话凭证后方可验证。
2. **`product_node` 的 `month` 不生效**：当前实现查本地 `amz_category` 快照表（无月份维度），`month` 仅做格式校验、不透传；官方 /api/9 支持历史月份。语义与官方不符。

### 🟡 P1（与官方有差异 / 映射未回归验证）
3. **`asin_competitor` 返回结构**：官方 `data` 为**数组**，本项目为分页信封 `{marketplace,page,size,total,pages,hasNextPage,items}`（为与同类接口统一）。未改。
4. **`market_research` 维度覆盖不全**：官方约 70 个参数中，上游 HTML 不提供的字段无法输出，包括 `currency`、`nodeLabelPath`、`nodeLabelPathLocale`、`totalRevenue`、`avgVolume`、`avgProfit`、`ebcProportion`、`sellerNation` 系列、`top3/5/10/20` 系列、`l1/l3/l6/l12` 系列。另有约 20 个筛选维度到上游表单名的映射为**按命名规律推断**，未逐个回归验证是否真正生效。
5. **`product_research` 的 matchType→selectType 映射存疑**：官方 `matchType` 为 1=词组/2=模糊/3=精准，而代码注释记载上游 `selectType` 为 2=模糊/3=词组/4=精准，存在移位嫌疑。本次仅做 1/2/3 校验，未改映射（避免臆测）。
6. **`keyword_research`**：`size` 默认/上限按官方改为 **15/15**（原 100/200）；约 8 个筛选项到上游 HTML 参数名（如 `minSearchesCr→minGrowth`、`minAraClickRate→minMonopolyClickRate`）为推断；新增的 `clicks`/`impressions` 的 HTML 取值顺序（TD7 内两个 div 的先后）需回归确认。
7. **`keyword_conversion`**：官方 `top10Asins` 上游无对应字段，改由上游 `gkDatas`(10 条) 映射，官方子字段（如 rank/badges）缺失时置 `null`。
8. **`traffic_keyword`**：`order.field` 到上游 `orderColumn` 的**数字编码**复用 `traffic_extend` 的映射，未与官方表 2.3 核对；`keyword` 过滤参数未透传上游（上游请求体无该字段）；上游 `trafficKeywordType` 返回数组（`["PRIMARY"]`）而官方示例为字符串/null，未强转。
9. **`traffic_extend`**：排序字段映射表缺官方表 2.5 的 `spr`/`adProduct`/`relationAsin`，传入这三个会回退默认排序。
10. **`traffic_listing`**：`variations` 默认 `true`，官方示例为 `false`（待确认取哪个）。
11. **`traffic_listing_stat`**：`asin` 字段恒为 `null`（上游聚合接口不返回单个 asin，官方 /api/15 为单 ASIN 查询才有值）。
12. **`keyword_miner`**：官方 `matchType` 取值为 2/3，当前默认 0 且未校验。

### 🟢 P2（约定 / 展示差异）
13. **size 规则**：`competitor_lookup`/`product_research` 默认 60、仅支持 20/60/100（按你的产品要求），与官方「默认 50、最大 100」不同。
14. **`amzSales`**：上游 `competing-lookup` 不返回该字段，`competitor_lookup`/`product_research` 按 `amzUnit × price` 推导（保留 2 位小数）；`asin_competitor`/`asin_detail` 走的上游本就返回原生 `amzSales`。
15. **`product_research` 的 `filterSub`**：官方为 String("Y")，本项目同时兼容 boolean 与 String。
16. **上游会话配额**：除 `asin_sales_trend` 外本轮均成功；长时间高频调用可能触发上游「数据为空」（配额耗尽），属环境限制。
17. **超出官方的额外字段**（上游有值、官方表未列，均保留）：
    - `competitor_lookup`/`product_research`/`asin_competitor`：`bsrLabel`、`nodeLabelPathLocale`、`bigImageUrl`、`questions`、`availableDays`、`firstReviewDate`、`coupon`、`revenueGr`、`salesTrend`、`amzUnitTrend`
    - `traffic_keyword`：`titleDensity`、`spr`、`monopolyClickRate`、`top3ClickingRate`、`top3ConversionRate`、`topAsins`、`searchesTrend`
    - `market_research`：`topAvgUnits`、`monopolyRatio`、`topAvgRevenue`、`topAvgBsr`、`goodsCrn`、`brandCrn`、`sellerCrn`、`newCount`、`newProportion`
