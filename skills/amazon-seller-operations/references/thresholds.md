# 判读阈值、计算公式与评分卡（全 Skill 唯一口径）

> 所有阈值为**方向性经验值**，优先与「同类目均值 / 头部均值 / 同级类目」对比使用；引用时标注"经验阈值"。
> 本文件是阈值的**唯一来源**，Playbook 只引用、不重复定义。字段单位见 tools-reference §0.7。

---

## 1. 多站点与币种规则

1. **本币原则**：价格、竞价、CPA、FBA 费都是站点本币。绝对金额阈值仅对 US 给出；其他站点用**相对口径**（占售价比例、相对类目均价），或按当日汇率粗略折算并标注"折算"。
2. **市场体量差异**：同一类目，非 US 站的搜索量/销量通常显著低于 US。需求阈值按站点缩放（经验系数，相对 US）：UK/DE ≈ 0.2~0.3，JP ≈ 0.2~0.3，FR/IT/ES/CA ≈ 0.1~0.15，MX/IN/AU/AE/BR/SA ≈ 0.05~0.1。最终仍以同站同类目均值为准。
3. **语言**：非英语站的关键词结论只对当地语言词有效。

## 3. 计算公式（涉及钱的结论必须算）

### 3.1 单位经济（P21）
```
到岸成本 C       = 采购价 + 头程（用户提供；未提供时提示，并按售价 25~35% 估算标注"假设"）
平台费 F         = 售价 × 佣金率(多数类目 15%，以类目实际为准) + FBA 费(product_research.fba / ss_keepa_info)
退货损耗 R       = 售价 × 退货率(returnRatio) × 损失系数(0.3~1.0，不可二次销售取 1)
广告前毛利 GP    = 售价 − C − F − R
广告前毛利率 GM  = GP / 售价
```

### 3.2 广告
```
盈亏平衡 ACOS    = GM
目标 ACOS        = GM − 目标净利率（新品期可临时 ≥ GM，成熟期 ≤ GM × 0.7）
最高可承受 CPC   = 售价 × 目标 ACOS × CVR
  · CVR 优先用自身广告报表；无则用 keyword_conversion.clickConvRate（市场值，标注）
出价判定         = exactPpc.value ≤ 0.7×最高CPC → 可投；0.7~1.0 → 精准小预算测试；> 1.0 → 不投或只投长尾
预估 ACOS        = exactCpa.value / 售价（市场基准，需传 customAvgProductPrice=售价）
冲首页成本 ≈ SPR × exactCpa.value（8 天内）
TACOS            = 广告花费 / 总销售额（需用户报表）；健康 ≤ 10~15%
```

### 3.3 BSR 与销量目标
```
目标日销 = bsr_prediction(categoryId, 目标BSR).estDailySales
达到目标 BSR 所需日广告单 = 目标日销 − 当前自然日销
```

### 3.4 备货
```
季节系数(月) = 该月销量 / 12 个月均值（asin_sales_trend.parentUnitSales；无数据用 google_trend 月值归一）
月需求       = 基准月销 × 季节系数
安全库存     = 日销 × (补货周期天数 × 0.5)，补货周期 = 生产 + 头程(海运 30~45 天) + 入仓(3~10 天)
补货点       = 日销 × 补货周期 + 安全库存
旺季发货时点 = 旺季首月 − 头程 − 入仓 − 2 周缓冲（Q4 入仓再加 2 周）
```

### 3.5 销量置信度
```
偏差 = |源A − 源B| / max(源A, 源B)
≤ 15% 高置信 | 15~30% 中 | > 30% 低（取区间，不给单点）
```

## 4. 评分卡

### 4.1 机会评分（P1/P8/P10/P13 统一输出）
| 维度 | 权重 | 数据来源 | 打分（绿 100 / 黄 50 / 红 0） |
|------|------|---------|------------------------------|
| 需求规模 | 20 | searches、avgUnits、totalUnits | §2.1/2.2 |
| 需求趋势 | 15 | growth、同比、ABA 排名、Google Trend | §2.6 |
| 竞争强度 | 20 | goodsCrn、brandCrn、monopolyRatio、araClickRate | §2.1/2.2 |
| 进入门槛 | 15 | avgRatings、SPR、新品销量占比、PPC 对比最高 CPC | §2.1~2.3 |
| 利润空间 | 20 | GM（§3.1）、profit、价格带 | §2.2 |
| 风险 | 10 | 退货率、自营占比、商标冲突、季节性 | §2.2/2.6 |

- **总分** = Σ(权重 × 得分) / 100。≥ 75 推荐进入；60~75 有条件进入（写明条件）；< 60 不建议。
- **缺失维度**：从分母中剔除并按比例放大其余权重，同时降一级置信度。
- **置信度**：高 = 6 维全有 + 销量两源一致；中 = 缺 1~2 维或销量偏差 15~30%；低 = 缺 ≥ 3 维或偏差 > 30%。
- **否决项**（任一命中即不推荐，与总分无关）：目标尼斯分类有 Registered 同名商标；GM < 10%；自营占比 > 50%。

### 4.2 ASIN 健康评分（P22）
| 维度 | 权重 | 指标 |
|------|------|------|
| 销量动能 | 25 | 近 30 天 vs 前 30 天、同比 |
| 流量健康 | 20 | 流量词数趋势、naturalRatio、核心词排名 |
| 转化质量 | 20 | EXCELLENT/LOST 结构、星级、评价增速 |
| 价格竞争力 | 15 | 是否在主销价格带、Buy Box 是否稳定 |
| Listing 完整度 | 10 | lqs 对比竞品、A+/视频、徽章 |
| 风险 | 10 | 跟卖、星级下滑、库存/断货迹象（BSR 突然断崖 + 价格异常） |

输出：总分 + 每维红黄绿 + 扣分最多的前 3 项及对应动作。
